# Копия сайта Благотворительного фонда «Алёша» (aleshafond.ru)

Точная, полностью автономная копия официального сайта благотворительного фонда «Алёша» (https://aleshafond.ru/).

## 📁 Структура проекта

- `index.html` — Главная страница
- `children.html` — Помочь детям (каталог детей, нуждающихся в помощи)
- `how-to-help.html` — Способы помощи (СБП, банковские карты, SMS, реквизиты)
- `post.html` — Поступления и отчеты
- `news.html` — Новости фонда
- `your-help.html` — Спасённые дети
- `about.html` — О фонде, руководство, документы, награды
- `need-help.html` — Подать заявку на помощь
- `contacts.html` — Контакты и реквизиты
- `faq.html` — Частые вопросы и ответы
- `teacher.html` — Акция «День учителя»
- `children-artyom-gorbunov.html`, `children-roma-erfurt.html` и др. — Карточки историй детей
- `assets/css/` — Локальные таблицы стилей (`main.css`, `jquery.fancybox.css`)
- `assets/js/` — Скрипты интерактивности (`app.js`, `paymentForm.js`, `ajax.js`)
- `assets/fonts/` — Оригинальные шрифты (Montserrat, Rubik, FontAwesome и др.)
- `assets/img/` — Иконки, SVG спрайты, логотипы, баннеры
- `storage/` — Скачанные фотографии детей и историй
- `serve.js` — Встроенный локальный HTTP-сервер для запуска в 1 команду

## 🚀 Как запустить

### Вариант 1. Запуск через встроенный Node.js сервер (Рекомендуется)
```bash
cd aleshafond_clone
node serve.js
```
После этого откройте браузер: **http://localhost:3000**

### Вариант 2. Прямое открытие в браузере
Вы можете просто открыть файл `index.html` двойным кликом в проводнике Windows. Все стили, шрифты, картинки и векторные SVG-иконки встроены автономно.
